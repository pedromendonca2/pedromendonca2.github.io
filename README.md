# Pedro Mendonça — Portfolio

Portfólio pessoal de **Pedro Henrique Mendonça**, engenheiro de IA e estudante de Ciência da Computação.

### [Acessar o site →](https://pedromendonca2.github.io/)

## Sobre o projeto

Site estático responsivo construído com HTML, CSS e JavaScript, sem dependências de runtime. A experiência apresenta trajetória, competências, formas de contato e projetos selecionados.

- Interface responsiva para desktop, tablet e celular.
- Conteúdo em português, inglês e alemão.
- Animações progressivas com suporte a `prefers-reduced-motion`.
- Navegação e componentes preparados para teclado e leitores de tela.
- Metadados para compartilhamento e mecanismos de busca.

## Projetos apresentados

- [LiftUp](https://github.com/pedromendonca2/liftup) — aplicativo fitness full stack com React Native, Expo, Node.js e PostgreSQL.
- [Tiresias](https://github.com/ia-ufes/2026-1-projeto-grupo-14) — pipeline de dados e machine learning para predição de aluguéis residenciais.
- [HackaTruck](https://hackatruck.com.br/) — programa de inovação com foco em desenvolvimento mobile, nuvem e IA aplicada.
- [TOV Adv](https://tovadv.com.br/) — website institucional para escritório de advocacia.

Os códigos desses projetos vivem em repositórios próprios. As pastas locais `LiftUp/` e `tiresias/` não fazem parte da aplicação do portfólio.
